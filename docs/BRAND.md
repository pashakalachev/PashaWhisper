# PashaWhisper brand

User direction: brutalist Soviet cute cat across the entire project.

Emblem: `assets/cat-emblem.png`, copied into the Swift package resources. Generated using the built-in image generation tool on September 6, 2026. A native simplified cat provides crisp menu-bar rendering. App icon sizes are exported during packaging.

## Original generation prompt

Use case: logo-brand. Asset type: macOS app icon for PashaWhisper, a personal speech-to-text app. Primary request: a cute cat logo in brutalist Soviet constructivist design. One striking flat emblem, square composition, oversized geometric cream cat face with triangular ears, friendly small black eyes, little geometric nose and whiskers; a simple red five-point star above the cat, bold angular charcoal silhouette, constructivist diagonal red block on warm cream paper. Cute and approachable yet architecturally stark. Palette exclusively vermilion red #C9362B, warm ivory #F2EBDD, ink charcoal #22231F. Large simple shapes that read at 32 pixels, sharp edges, balanced negative space, crisp solid fills. Entire square image, no rounded app icon mask, no mockup, no text or letters, no gradients, no shadows, no 3D, no watermark, no tiny decorative details.

## Interface tokens

- Paper: #F2EBDD
- Ink: #22231F
- Red: #C9362B
- Native system sans serif; condensed black headings; monospaced metadata.
- Square controls, black rules, no gradients, and no decorative motion.
- Functional copy stays direct; cat wordplay is reserved for headings and empty states.


## Final refinement

The final clean emblem is assets/cat-emblem.png. The original textured version is preserved as assets/cat-emblem-v1.png. Both were made with the built-in image tool. The complete final edit prompt is in LOGO_PROMPT.txt.

## Recording overlay refinement — September 7, 2026

The overlay is intentionally softer and smaller than the main interface: a dark capsule, central cream cat, and five short rounded waveform bars radiating on each side. Use a red progress arc during finalization, with a static arc for Reduce Motion. Do not show time, model, shortcut, or recording labels. Screen-reader labels describe state; detailed errors remain in the main app.
